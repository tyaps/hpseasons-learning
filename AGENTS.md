# Правила для агентов и разработчиков

- Источник истины по требованиям — `docs/SPEC.md`.
- Любое изменение или дополнение требований **сначала** вносится в `docs/SPEC.md` (с записью в раздел «История изменений»), и только потом в код.
- После завершения работы сверяйте `docs/SPEC.md` с реализацией: они не должны расходиться.
- Контент (вопросы и правила) пишется в `content/` (YAML/Markdown). Каталог `public/data/` генерируется (`npm run content`) и не коммитится.
- Перед завершением работы запускайте: `npx vue-tsc --noEmit`, `npx vitest run`, `npm run build`.
