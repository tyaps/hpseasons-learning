## Описание, атака и удержание {#profile}

| Название | Безликий |
| ----- | :---- |
| Описание | Полностью черная фигура без мантии и других развевающихся элементов, чёрная ткань скрывает лицо, вместо волшебной палочки белая пёсья кость в руке |
| Поведение | Может колдовать и говорить. Использует чары. Может отдать приказ инфери, упырям. Если заглянуть под маску Безликого, то волшебник сойдет с ума. |
| Перемещение | Шаг, бег (как волшебник). Не может пересечь соляной круг. |
| АтакаА     	Атака | Чары боевые Симпла+Максима. (без ультим, без веерных) Морфеус, Силенциум, Круцио (Сим) Империо (Сим) \- редко\! Аппарировать не способен.  Проклятие Авада Кедавра применять не может. **Может использовать чары, которыми владеет оператор.** |
| Удержание | Нет |
| Двери | Колопортус Симпла, Максима (если оператор знает бытовые чары, открывающие их) |
## Уязвимости и взаимодействие с магией {#vulnerabilities}

| **УЯЗВИМОСТИ (Принцип: если не сказано, значит НЕ работает)** |  |
| Чары | Все неотбитые чары  обездвиживают на 5 минут. Если в течение часа использовать Инсендио Ультима каждые 5 минут, то сгорает полностью. (ошибочный закл увеличивает время горения на 10 минут) Если применить формулу "Exorciso te, N, omnis spiritus immundus", где N \- расшифрованное имя, которое написано на теле Безликого в виде анаграммы \- рассыплется сам. Можно выбить или трансфигурировать кость в руки, найдет новую за 3 секунды. |
| Непростительные | Нет |

* Не может войти внутрь соляного кольца, в котором с чувством читают возвышенные стихи. Но может кинуть внутрь круга заклинание. Может сжигать просо для упырей.  
* Мёртвое тело, которое управляется волей оператора (это не обязательно проводивший ритуал некромант). Тело оператора находится где угодно в бессознательном состоянии, обычно далеко и в безопасности.  
* Любое взаимодействие с Безликим влияет только на самого Безликого. Невозможно навредить оператору через Беликого, можно только разорвать их связь, после чего оператор очнется невредимым.  
* Узнать в Безликом оператора нельзя, голос и лицо принадлежат мертвому телу. Но, так как Безликие могут говорить, бывает, что они во время переговоров выдают настоящие имена операторов, говоря между собой.
