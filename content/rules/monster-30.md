## Описание, атака и удержание {#profile}

| Название | Карпатский Йети | ![Карпатский Йети](data/assets/monsters/image30.png) |
| :---- | :---- | :---: |
| Описание | Лохматое существо белого (седого) цвета. Как снежный человек. Огромная козлоподобная тварь, местами снежный человек, местами козел |  |
| Поведение | Бежит как бешеная горилла, пытается всех разорвать. Не может войти внутрь соляного кольца, в котором с чувством читают возвышенные стихи. |  |
| Перемещение | Шаг, бег. Не может войти в соляной круг, если там читают стихи и пр. |  |
| АтакаА     	Атака | Когти \- рваные некрораны. Выводит волшебника из строя за 3 секунды. Отгрызает конечность за 1 минуту. Загрызает насмерть за 5 минут. Некоторые волшебники владеют способностью "крепкое тело", и грызть их придётся в 2 раза дольше. |  |
| Удержание | Да. |  |
| Двери | Незапертые магически двери |  |
