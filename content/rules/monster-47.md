## Описание, атака и удержание {#profile}

| Название | Пикирующий злыдень | ![Пикирующий злыдень](data/assets/monsters/image47.png) |
| :---- | :---- | :---: |
| Описание | Крупное существо, похожее на ската. |  |
| Поведение | Существо летает, сворачивается в кокон и разворачивается. |  |
| Перемещение | Полет |  |
| АтакаАА   	Атака | Нужно схватить волшебника. Присасывается к лицу жертвы. Яд подменяет воспоминания за последние 45 минут на хаотичные и смешанные (тут помню, тут не помню). Начинается эффект Ахелитус Ультима (смерть через 45 минут), нужно продолжать. Если злыдень отвлечется или свернется, то удушье спадет. Высасывает мозг через ноздри (постэффекты на откуп игрока). |  |
| Удержание | Да |  |
| Двери | Незапертые двери, узкие щели |  |

 **Биом**: Лес.

 **Интересные факты:**

* Пикирующий злыдень в неактивном состоянии похож на большой и колючий тропический плод зеленого цвета, что помогает ему скрыться днем у всех на виду. Хвост злыдня приспособлен, чтобы долго висеть на деревьях. 


 **Возможные сценки для отыгрыша:**

| Пикирующие злыдни | друг с другом | свой биом | свое время | июль \- август | Во время выкармливания могут делиться друг с другом едой как вампиры, формируя материнские колонии, направленные на заботу о потомстве. В это время самцы разлетаются, не участвуя в выращивании детенышей |
